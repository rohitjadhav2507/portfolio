# Personal Portfolio Website

This is a personal portfolio website developed by Rohit Jadhav as part of the IBM Full Stack / Front-End Software Developer program.

## Sections
- **Profile & Navigation Bar:** Personalized header with Rohit Jadhav's name, contact information, working home button, and navigation links.
- **About Me:** Professional introduction and background.
- **Skills:** 5 formatted skills with visual logos (HTML5, CSS3, JavaScript, React, Node.js).
- **Project Details:** Showcase of technical projects (Chatbot, Sentiment Analyzer, eCommerce).
- **Recommendations:** Dynamic recommendation list with interactive submission form and confirmation popup modal.
